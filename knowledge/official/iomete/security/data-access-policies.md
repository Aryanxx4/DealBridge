# Data access policies (database, table and column)

## Summary

IOMETE data access policies assign permissions to users or groups. A policy selects databases,
tables and columns, each of which can be included or excluded, and wildcards are supported in names.
Conditions include allow, exclude from allow, deny and exclude from deny. Policies can be enabled or
disabled, can override other policies, and can have a validity period.

## Details

- Policy resources: Databases, Tables, Columns (include or exclude).
- Wildcards: * and ? in database, table or column names.
- Optional validity period with start and end time.
