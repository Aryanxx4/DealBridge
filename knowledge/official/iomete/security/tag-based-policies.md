# Tag-based policies and data classifications

## Summary

Besides resource-based policies, IOMETE supports tag-based access and masking policies that apply
controls to every resource carrying a tag. Data classifications label tables and columns (for
example PII, Confidential, Financial) and follow a request-and-approval workflow, so adding or
removing a classification requires approval and is tracked.

## Details

- Tag-based access policy and tag-based masking policy.
- Classifications are predefined by admins or security teams.
- Changes are tracked through Classification Requests.
