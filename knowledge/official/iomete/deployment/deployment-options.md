# Deployment options and data residency

## Summary

The IOMETE overview states that the platform can be deployed on-premises, in the cloud, or in a
hybrid environment. It also states that the platform operates entirely within the customer's
infrastructure and that no data is sent outside the organization. The Enterprise Edition is
described as offering a control plane and multi-data plane architecture for deploying across
multiple regions.

## Details

- Deployment targets named on the overview page: on-premises, cloud, hybrid environment.
- Data security and privacy section: the platform runs inside the customer's infrastructure; no data is sent outside the organization.
- Multi-region: Enterprise Edition describes a control plane plus multiple data planes, managed from a single control plane, for disaster recovery, high availability and multi-region deployments.
