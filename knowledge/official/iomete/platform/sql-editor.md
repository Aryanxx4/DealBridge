# SQL Editor

## Summary

The SQL Editor is IOMETE's browser-based environment for writing, running and visualizing SQL
queries on compute clusters. It supports real-time collaboration and Git integration for version-
controlled SQL files. Work is organized into workspaces, folders, worksheets and dashboards.

## Details

- Results render as a data grid, chart or raw SQL.
- Building blocks: workspace, folder, worksheet, dashboard.
- SQL Editor V2 runs multiple statements with per-result tabs.
