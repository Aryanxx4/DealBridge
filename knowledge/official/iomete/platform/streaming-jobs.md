# Streaming jobs

## Summary

Streaming jobs are long-running Spark applications for continuous processing such as real-time
ingestion and event processing. Unlike regular Spark jobs they run until stopped, have no schedule,
and run one application at a time per job.

## Details

- Started and stopped manually.
- Python or JVM applications.

## Source excerpts

> Streaming Jobs are long-running Spark applications built for continuous data processing: real-time ingestion, event processing, and anything that needs always-on execution.
