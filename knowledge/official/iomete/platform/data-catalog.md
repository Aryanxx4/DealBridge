# Data Catalog

## Summary

The Data Catalog lets users search, browse and tag every table from one place. A scheduled Catalog
Sync Job indexes metadata automatically. The interface offers full-text and semantic search, a
hierarchical data explorer, favorites, classifications and an approval workflow for classification
requests.

## Details

- Only indexed data appears until the next Catalog Sync Job.
- Requires the View Data Catalog role permission.
