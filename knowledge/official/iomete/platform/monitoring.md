# Monitoring

## Summary

The admin portal's Monitoring page is a directory of monitoring surfaces: control-plane health,
namespace resource usage, SQL query monitoring and search engine metrics, plus any external Grafana
dashboards the organization links. Any admin role can open it.

## Details

- Cards: Control-Plane health, Namespace quotas overview, SQL query monitoring, Search engine (Typesense).
- External Grafana dashboards appear in a separate section when configured.

## Source excerpts

> Monitoring is the admin portal's directory of every platform-wide monitoring surface in IOMETE: control-plane health, namespace resource usage, query activity, search engine metrics, and any external Grafana dashboard your organization has configured.
