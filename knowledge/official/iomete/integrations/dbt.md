# dbt adapter

## Summary

The dbt-iomete adapter connects dbt to the IOMETE lakehouse with Iceberg support, giving versioned
SQL transformations on open table formats. Prerequisites are a running IOMETE compute cluster and
Python 3.9 or later.

## Details

- Adapter: dbt-iomete.
- Guide seeds sample Iceberg tables before the first dbt project.
