# Apache Superset connection

## Summary

The documentation includes a guide for connecting Apache Superset to IOMETE. Superset needs a Python
database driver for IOMETE (py-hive-iomete), which the guide installs into a Docker Compose based
Superset setup.

## Details

- Driver package named in the guide: py-hive-iomete.
