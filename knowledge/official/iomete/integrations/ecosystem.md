# Third-party ecosystem integrations

## Summary

The integrations overview lists third-party tools for governance, observability, analytics and
storage: Ataccama, ThoughtSpot, Monte Carlo, OpenMetadata, Collate, Wasabi and Stardog. Each card
links to the vendor's own documentation.

## Details

- OpenMetadata: cataloging, profiling and lineage of IOMETE tables.
- Wasabi: S3-compatible storage for Iceberg data and metadata.
