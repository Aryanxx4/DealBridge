# Query federation

## Summary

IOMETE can query several sources in one SQL statement. The documented sources are IOMETE-managed
Iceberg tables, files in object storage (CSV, JSON, Parquet, ORC), JDBC sources such as MySQL,
PostgreSQL and Oracle, and Snowflake tables.

## Details

- Example joins MySQL, PostgreSQL, a CSV file and a Snowflake table.
