# Migrating tables from JDBC sources

## Summary

IOMETE provides an end-to-end tutorial for migrating tables from JDBC sources such as MySQL or
PostgreSQL into IOMETE and showing them in a BI dashboard. The tutorial notes that an SSH tunnel is
first needed between IOMETE and a database in a private network.

## Details

- Covers replicating a MySQL (or other JDBC) database into IOMETE.
