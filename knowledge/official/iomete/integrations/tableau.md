# Tableau connection

## Summary

IOMETE documents two ways to connect Tableau: Arrow Flight with the IOMETE Arrow Flight SQL
connector, which is the recommended method, and Thrift with Tableau's built-in Spark SQL connector
or the CData Spark SQL connector. Once connected, dashboards are built in Tableau as usual.

## Details

- Recommended method: Arrow Flight.
- Thrift alternative: built-in Spark SQL connector or CData Spark SQL connector.
