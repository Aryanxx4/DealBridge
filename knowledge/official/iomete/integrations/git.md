# Git integration for SQL worksheets

## Summary

From platform version 3.1.0, IOMETE supports Git integration for hosting SQL worksheets in Git
repositories accessed from the SQL editor. GitLab is the initial and currently only supported
provider.

## Details

- Register a repository with URL, name, provider and token.

## Source excerpts

> Starting from version 3.1.0 of the IOMETE platform, we now support Git integration, with GitLab as our initial Git provider.
