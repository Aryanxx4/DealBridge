# Metabase connection

## Summary

The documentation includes a guide for connecting Metabase to an IOMETE compute cluster. IOMETE is
added in Metabase with the Spark SQL database type, using connection values from the compute cluster
details page and a personal access token as the password.

## Details

- Database type: Spark SQL.
- Password field: personal access token.
