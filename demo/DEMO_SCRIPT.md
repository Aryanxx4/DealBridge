# DealBridge demo script

Run `make reset-demo` first. It deletes demo assessments, chats, tickets and expert answers, and keeps the official knowledge. Then start the app (`make dev-backend`, `make dev-frontend`) and open http://localhost:5173. Switch identities with the dropdown at the top right. Demo identities are **not** authentication.

**Honesty rule.** The "Observed" lines below record what was actually seen when the step was run against real services (PostgreSQL, Qdrant, the local embedding model). Steps that need the language model show **"Not yet observed: requires LLM_API_KEY"**. Their expected statuses are deliberately not pre-written; record them after running the step with a key. Statuses depend on the real model's judgement plus the deterministic guardrails.
